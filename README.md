# 🦘 Australia Zoo Website

A fully responsive, multi-page educational website showcasing animals from the Australia Zoo.  
Built with **HTML**, **CSS**, and **JavaScript**, and developed as a collaborative team project.

---

## 🌐 Live Demo  
🔗 **https://australia-zoo-self.vercel.app**

---

## ✨ Features  
- 📱 **Responsive Layout** — Works across mobile, tablet and desktop  
- 🧭 **Intuitive Navigation** — Home, About, Mammals  
- 🦁 **Mammals Gallery** — Species profiles with images and descriptions  
- 🧼 **Clean HTML5 Structure** — Semantic and organized  
- 🎨 **Modern CSS Styling** — Consistent, maintainable layout  
- ⚡ **JavaScript Interactivity** — Mobile menu toggle and UI behaviors  
- 📁 **Scalable Folder Structure** — Ideal for teamwork and future enhancements

## 🚀 Getting Started  

### 📥 Installation
```bash
git clone https://github.com/ArashSafarighouzhdi/Australia-Zoo.git
cd Australia-Zoo
```

Open `index.html` directly in your browser, or serve it through a local development server.

## 🤝 Contribution Workflow  

### 👥 Team Members  
Sandra • Raana • Chaitali • Smita • Arash Safari

### 🔖 Branch Naming Convention  
```
type/short-description
```
Examples:  
- `feature/homepage-layout`  
- `fix/navbar-responsiveness`  
- `update/readme-design`

### 📝 Process  
1. Create a new branch from `main`  
2. Implement your feature or fix  
3. Write clear commit messages in present tense  
   - Example: `Add mobile navigation animation`  
4. Push the branch and open a Pull Request  
5. At least **two team members must approve** before merging  

### 🔍 Code Review Checklist  
Reviewers should verify:  
- Code readability and structure  
- HTML/CSS/JS best practices  
- Correct and stable functionality  
- Responsive behavior across devices  
- No console errors  
- Clean commit history  

### 🧪 Testing Before Merge  
Ensure:  
- All navigation links work  
- Layout is responsive on all screen sizes  
- Images load correctly  
- JavaScript interactions behave as expected  
- HTML and CSS validate without issues
